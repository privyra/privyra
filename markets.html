Markets

The equity catalogue, with the lights labeled.

These are the names the night clerks watch: listed companies and a few index funds a tokenized desk would quote. A figure appears only when a public, CORS-open bundle has a close. The rest of the row stays blank on purpose. This is not a live tape and it is not a solicitation.

Last close is the session date in the row, compared with the prior session in the bundle. It is not a live last price.

Closes that carry a date are from Fin-node public bundles, which send Access-Control-Allow-Origin: * and describe themselves as a daily snapshot. Yahoo’s chart endpoint does not allow a browser on this origin to read it, so it is not used. A future live tape can be pointed at markets.quoteUrl in the config. Symbols with no bundle — including HOOD, MSTR, the index funds, and most names outside Fin-node’s thirty — show an em dash.
