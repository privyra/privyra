Ink transfer

Pay the seal. Leave the wallet out of the story.

An ink transfer is a payment to an address that exists for that payment. The recipient recognizes it with a viewing key kept in their own session. Everyone else sees a transfer to a stranger. The announcer that would publish the seal is not deployed, so this page builds the letter and stops before the signature.

The four beats

  1. You name the recipient and the amount.
  2. This page would draw an ephemeral key locally. It does not, until a registry can publish the recipient’s viewing key.
  3. The chain would see the seal address and an announcement, not your note.
  4. The recipient’s session would test the announcement and, on a match, spend from the seal.

Keys for that dance are not stored by Privyra. When the feature is wired, they live in memory for the session, the same way a signature prompt does. Anyone who can sign for your wallet would be able to unlock the same seal. Treat the wallet accordingly.
